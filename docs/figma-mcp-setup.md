# Настройка MCP сервера для работы с Figma

## Обзор

Данная инструкция описывает процесс настройки и использования MCP (Model Context Protocol) сервера для взаимодействия с Figma через плагин "Cursor Talk To Figma" в редакторе Cursor.

## Предварительные требования

1. **Figma Desktop App** - установленное приложение Figma (не веб-версия)
2. **Cursor IDE** - установленный редактор Cursor
3. **Bun** - пакетный менеджер для запуска MCP сервера (устанавливается автоматически или вручную)

## Шаг 1: Установка плагина в Figma

1. Откройте приложение **Figma Desktop**
2. Откройте любой файл в Figma (или создайте новый)
3. Перейдите в меню: **Plugins → Browse plugins in Community**
4. Найдите плагин **"Cursor Talk To Figma"** или **"Talk To Figma"**
5. Нажмите **Install** для установки плагина
6. После установки плагин появится в меню **Plugins → Cursor Talk To Figma**

## Шаг 2: Настройка MCP сервера в Cursor

### 2.1. Расположение конфигурационного файла

Файл конфигурации MCP находится по пути:
```
~/.cursor/mcp.json
```

### 2.2. Конфигурация сервера

Убедитесь, что в файле `mcp.json` присутствует следующая конфигурация:

```json
{
  "mcpServers": {
    "TalkToFigma": {
      "command": "bunx",
      "args": ["cursor-talk-to-figma-mcp@latest"]
    }
  }
}
```

**Примечание:** Если у вас уже настроены другие MCP серверы (например, Dart), просто добавьте секцию `TalkToFigma` в объект `mcpServers`.

### 2.3. Проверка установки Bun

MCP сервер использует `bunx` для запуска. Если `bunx` не установлен:

**macOS/Linux:**
```bash
curl -fsSL https://bun.sh/install | bash
```

**Windows:**
```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

После установки перезапустите Cursor.

## Шаг 3: Запуск плагина в Figma

1. Откройте **Figma Desktop**
2. Откройте файл, с которым хотите работать
3. Перейдите в меню: **Plugins → Cursor Talk To Figma → Start Plugin**
4. Плагин отобразит **канал (channel ID)** - это уникальный идентификатор для подключения
5. Скопируйте этот **channel ID** - он понадобится для подключения из Cursor

**Важно:** Плагин должен быть запущен и активен во время работы с Figma через Cursor.

## Шаг 4: Подключение к каналу из Cursor

После запуска плагина в Figma, подключитесь к каналу из Cursor:

1. В Cursor откройте чат с AI ассистентом
2. Используйте команду для подключения к каналу:
   ```
   join_channel с channel: "ваш_channel_id"
   ```
   Например: `join_channel с channel: "5txx3xvk"`

3. После успешного подключения вы увидите сообщение:
   ```
   Successfully joined channel: "ваш_channel_id"
   ```

## Шаг 5: Основные команды для работы с Figma

После подключения к каналу вы можете использовать следующие команды:

### Получение информации о документе
```
get_document_info
```
Возвращает информацию о текущем документе Figma: страницы, структуру и т.д.

### Получение информации о выделении
```
get_selection
```
Возвращает информацию о текущем выделенном элементе в Figma.

### Чтение дизайна
```
read_my_design
```
Получает детальную информацию о выделенном элементе, включая все свойства узла.

### Получение информации о конкретном узле
```
get_node_info с nodeId: "node_id"
```

### Создание элементов

**Создание прямоугольника:**
```
create_rectangle с x: 100, y: 100, width: 200, height: 150
```

**Создание фрейма:**
```
create_frame с x: 0, y: 0, width: 400, height: 300
```

**Создание текста:**
```
create_text с x: 50, y: 50, text: "Привет, мир!"
```

### Изменение свойств элементов

**Изменение цвета заливки:**
```
set_fill_color с nodeId: "node_id", r: 0.5, g: 0.8, b: 1.0
```

**Изменение цвета обводки:**
```
set_stroke_color с nodeId: "node_id", r: 0, g: 0, b: 0, weight: 2
```

**Перемещение элемента:**
```
move_node с nodeId: "node_id", x: 200, y: 200
```

**Изменение размера:**
```
resize_node с nodeId: "node_id", width: 300, height: 200
```

## Примеры использования

### Пример 1: Получение информации о документе

1. Запустите плагин в Figma и скопируйте channel ID
2. В Cursor подключитесь к каналу
3. Выполните команду `get_document_info`
4. Получите структуру документа

### Пример 2: Создание простого UI элемента

```
1. create_frame с x: 0, y: 0, width: 375, height: 812, name: "Mobile Screen"
2. create_text с x: 20, y: 50, text: "Заголовок", fontSize: 24, parentId: "frame_id"
3. set_fill_color с nodeId: "frame_id", r: 0.95, g: 0.95, b: 0.95
```

### Пример 3: Работа с выделенным элементом

1. Выделите элемент в Figma
2. В Cursor выполните `get_selection`
3. Получите информацию о выделенном элементе
4. Используйте `read_my_design` для детальной информации

## Устранение неполадок

### Ошибка: "Not connected to Figma"

**Причина:** Плагин не запущен в Figma или не подключен к каналу.

**Решение:**
1. Убедитесь, что плагин запущен в Figma Desktop
2. Проверьте, что вы подключились к правильному каналу
3. Перезапустите плагин в Figma и подключитесь заново

### Ошибка: "Must join a channel before sending commands"

**Причина:** Не выполнено подключение к каналу.

**Решение:**
1. Запустите плагин в Figma
2. Скопируйте channel ID
3. Выполните `join_channel` с правильным channel ID

### Ошибка: "Request to Figma timed out"

**Причина:** Плагин не отвечает или потеряно соединение.

**Решение:**
1. Проверьте, что плагин все еще активен в Figma
2. Перезапустите плагин
3. Переподключитесь к каналу

### Ошибка: "bunx: command not found"

**Причина:** Bun не установлен или не добавлен в PATH.

**Решение:**
1. Установите Bun (см. Шаг 2.3)
2. Перезапустите Cursor
3. Проверьте, что `bunx` доступен в терминале: `which bunx`

### MCP сервер не запускается

**Решение:**
1. Проверьте синтаксис JSON в файле `mcp.json`
2. Убедитесь, что путь к `bunx` корректен
3. Перезапустите Cursor для перезагрузки конфигурации MCP
4. Проверьте логи Cursor на наличие ошибок

## Полезные советы

1. **Всегда запускайте плагин первым** - перед подключением из Cursor убедитесь, что плагин активен в Figma
2. **Используйте правильный channel ID** - каждый запуск плагина генерирует новый channel ID
3. **Работайте с одним каналом** - не запускайте несколько экземпляров плагина одновременно
4. **Сохраняйте channel ID** - если нужно переподключиться, используйте тот же channel ID (пока плагин активен)
5. **Проверяйте выделение** - многие команды работают с выделенными элементами в Figma
