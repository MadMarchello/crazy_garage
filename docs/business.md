# Основной функционал проекта 

1. Блог-цифровой сад с моими `.md` заметками и связями между заметками с картой. 
2. Медиаплеер для прослушивания музыки закрытый под авторизацией (админской)
3. Файлохранилище с интеграцией с Яндекс.Диск
4. Центр управления (админ-панель) со статистикой состояний всех моих микросервисов
