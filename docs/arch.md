# Архитектура моего оверинженерного гаража
## Основная концепция
Данное приложение есть "полигон" для обкатки совершенно разных технологий. 

Основные правила "оверинженернутого" клуба: 
1. Забываем про здравый смысл и используем high-load техники с микросервисной архитектурой и распределением данных через брокеры сообщений для полутора землекопов-пользователей сервиса.
2. Используем разные языки, разные виды СУБД, разные паттерны микросервисной архитектуры.
3. Код пишем максимально в соответствии с SOLID и DDD.

В конечном итоге - проект должен стать "сервисом" чтобы править всеми" в будущем homelab, который я хочу построить. 


## Фронтенд
Используем разные фреймоврки и библиотеки для разных частей интерфейса через Микрофронтенды. 

Список технологий (будет пополняться по мере вдохновления и изучения):
1. Flutter
2. React
3. Vue
4. Angular
5. Svelte

## Бэкенд 
Используем микросервсиную архитектуру. На каждый микросервис по своей отдельной технологии (например, для сервиса пользователей - Dart, для сервиса заказов - Elixir, для сервиса аналитики - Python, etc).

Список технологий (будет пополняться по мере вдохновления и изучения):
1. Dart 
2. Elixir
3. Python
