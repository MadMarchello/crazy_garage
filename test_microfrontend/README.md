# Test Microfrontend - Счетчик

Микрофронтенд со счетчиком для интеграции в shell-приложение.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:3001`

## Сборка

```bash
npm run build
```

## Использование

Этот микрофронтенд интегрирован в shell-microfrontend и загружается через iframe на порту 3001.
